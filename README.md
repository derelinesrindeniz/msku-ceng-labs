# Java Programming Labs

This repository contains Java lab exercises completed as part of my university coursework.

The labs focus on basic Java programming, object-oriented programming, and problem-solving skills.

## Technologies Used

- Java
- IntelliJ IDEA

## Topics Covered

- Variables and data types
- Conditional statements
- Loops
- Arrays
- Methods
- Classes and objects
- Object-oriented programming basics
- Basic algorithms

## What I Learned

Through these lab exercises, I improved my Java programming fundamentals and practiced solving problems using basic programming concepts and object-oriented programming principles.

## How to Run

Open the project in IntelliJ IDEA or any Java-supported IDE and run the selected Java file.
